# terremotos_venezuela
Análisis rapido del dataset elaborado por Microsoft AI for Good - Building damage visualizer para detectar edificios e infraestructuras colapsadas o con daños severos a los fines de coordinar las acciones de rtespuesta inmediata de los equipos de rescate y atención medica a las victimas.   Fuente: https://data.humdata.org/event/venezuela-earthquake
